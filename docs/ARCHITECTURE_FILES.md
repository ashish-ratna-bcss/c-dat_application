# C-DAT file layout and URL aliases

## What to edit

Edit **canonical real files** at the repository root (and module folders), for example:

- `HOME.html`
- `LOGIN.PHP` / `LOGIN.HTML`
- `ADDRESS.PHP` / `ADDRESS.HTML`
- `sqlsrv_compat.php`, `db_config.php`, upload/admin PHP modules

Use `docs/url_alias_manifest.csv` or `SYMLINK_CANONICAL_TOPLEVEL.csv` to see which file is canonical for a page stem.

## What `old_versionfiles/` is

`old_versionfiles/` holds an **archive** of the old URL-alias symlinks (thousands of casing / `.htm` / `.html` variants).

- Generated by: `python3 scripts/archive_url_aliases.py`
- **Gitignored** — not part of the live app
- Link names under `old_versionfiles/links/` are case-safe (`^` before each uppercase letter) so macOS can store them
- Full mapping: `old_versionfiles/MANIFEST.csv` (local) and `docs/url_alias_manifest.csv` (tracked)

Do **not** point the web root at `old_versionfiles/`. Nginx denies `/old_versionfiles/`.

## How old URLs still work on Linux

1. Include the map in the nginx `http {}` block:

```nginx
include /mnt/storage1/cdat-web/scripts/nginx-url-alias-map.conf;
```

2. Use [`cdat-web.nginx.conf`](../cdat-web.nginx.conf), which rewrites mapped URIs to the canonical real file.

Example: `/home.html` → `/HOME.html`.

Regenerate the map after alias inventory changes:

```bash
python3 scripts/archive_url_aliases.py
# then rebuild scripts/nginx-url-alias-map.conf (see scripts or re-run archive tooling)
```

## macOS note

This project’s working tree is often checked out on a **case-insensitive** volume. Do not recreate root-level `home.html` → `HOME.html` aliases locally (they loop). Edit the canonical real file only.
